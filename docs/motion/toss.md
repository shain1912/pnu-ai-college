# toss.im 모션 관찰 — 히어로 진입과 전체 스크롤

관찰일: 2026-08-22  
뷰포트/캡처: `capture-motion.mjs` 기본 데스크톱 뷰포트  
캡처 세트: `toss-load-50`(24프레임, 50ms), `toss-load-20`(30프레임, 20ms), `toss-scroll-32`(33프레임, settle 200ms), `toss-scroll-64-120`(65프레임, settle 120ms)

## 1. 히어로 진입

- `toss-load-20` 프레임 000은 내비게이션만 있고 본문은 흰색이다. 프레임 001에서 영상 카드가 좌우 약 5px, 위쪽 약 45px의 인셋과 큰 모서리 라운드를 가진 상태로 한 번에 포착된다. 프레임 002까지 같은 인셋 상태이고, 프레임 002→003 사이에는 좌우 여백이 사라지며 영상이 뷰포트 폭까지 확장된다. 프레임 간격 기준으로 보이는 마지막 확장 구간은 약 20ms다.
- 다만 애니메이션 시작은 프레임 000→001 사이의 영상 로딩과 겹쳐 캡처되지 않았다. 따라서 기존의 “약 300ms 전체 확장”은 이번 프레임만으로 재확인하지 못했다. 이번에 확실히 관찰한 것은 첫 영상 노출 뒤 프레임 001→003, 약 40ms 안에 인셋 카드가 풀블리드가 된다는 점이다.
- 단어 등장도 초반에 몰린다. `toss-load-20` 프레임 001에서 “금융부터 일상까지”는 거의 완전 불투명, “마침내”는 약 0.45, “토스 하나로”는 관찰되지 않는다. 프레임 001→002 사이(약 20ms)에 “마침내”가 완전 불투명해지고 “토스 하나로”도 완전 불투명 상태로 나타난다. 프레임 002→003에서는 세 어절 모두 밝기가 유지된다.
- 따라서 순서는 **금융부터 일상까지 → 마침내 → 토스 하나로**로 재확인했다. 다만 뒤 두 어절 사이의 별도 지연은 20ms 샘플에서도 중간 프레임이 없어 특정 불가하며, 관찰 가능한 상한은 둘 다 프레임 001→002의 20ms 구간이다.

## 2. 전체 스크롤: 총 10개 시각 챕터

푸터를 별도 챕터로 포함해 총 10개로 셌다. 한 챕터 안에서 문구와 제품 장면이 여러 번 바뀌는 경우는 하나의 동일한 sticky 무대로 묶었다.

1. **송금 히어로 / 실사 영상** — `toss-scroll-64-120` 000~007. 열차 안 여성이 휴대폰을 보고 송금 금액을 입력한 뒤 완료 체크가 뜬다.
2. **자산관리 / 3D 폰 렌더** — 008~012. 실사 화면이 라운드 카드로 축소되고 기울어진 폰 렌더로 넘겨진다. 폰은 화면 오른쪽에 고정되고 왼쪽 카피만 단계적으로 바뀐다.
3. **증권 / 어두운 UI 카드** — 013~015. 주식 용어 카피 아래 검은·회색 UI 카드가 보이다가 위로 빠진다. 짧아서 200ms 캡처에서는 거의 한 장면만 잡힌다.
4. **쇼핑 / 실사 박스 + 폰 목업** — 016~025. 상자가 흰 배경에서 실사 주방으로 바뀌고(016→017), 뚜껑이 열린 뒤 병이 튀어나온다(018→019). 이어 상품 상세 폰, 결제 시트, 결제 완료가 차례로 교체된다(020~025).
5. **판매·정산 / 상품 카드 레일** — 026~029. “상품 판매와 정산” 카피가 옅게 들어온 뒤 상품 카드들이 가로 레일로 늘어서고, 정산 숫자 카드로 전환된다.
6. **토스애즈 / 광고 카드 레일** — 030~035. 달력형 카드에서 여러 광고 포맷 카드가 가로로 이동하며, 마지막에는 점으로 된 데이터 지형/그래프가 나타난다.
7. **토스페이먼츠 / 데스크톱 관리자 UI** — 036~039. 흰 배경의 웹 대시보드가 커지며 폼/결제 UI와 카피가 바뀐다.
8. **온·오프라인 결제 / 검은 인터스티셜 + 단말기 실사·렌더** — 040~053. 중앙 검은 캡슐이 세로로 커지고(040→041), 화면 전체 검정 타이틀로 전환된다(041→042). 이후 매장 카운터의 단말기, 키오스크, 태블릿, 얼굴 확인 결제 장면이 같은 어두운 실사 무대에서 교체된다.
9. **토스가 바꾼 일상 / 카드 모자이크 + 여행 실사 영상** — 054~061. 작은 생활 사진 카드가 차례로 채워지고(054~057), 검정 배경 중앙의 비행기 창 카드로 축소된 뒤(058→059) 비행기 승객과 창밖 노을 영상으로 확장된다(059~061).
10. **글로벌 피날레·푸터 / 블루 그라데이션 구체** — 062~064. 짙은 남색 배경의 와이어프레임 지구와 글로벌 카피가 나오고, 같은 배경을 유지하며 링크 푸터로 내려간다.

## 3. 텍스트 크로스페이드 범위

아래 범위는 64등분 전체 스크롤에서의 프레임 번호이며, 절대 px 스크롤값은 캡처 결과에 기록되지 않아 관찰 못함이다.

- 첫 히어로 카피는 002→004에서 사라진다. 프레임 003에서 “토스 하나로”가 약 0.35 불투명도로 흐려지고, 004에서는 이전 문구가 화면 아래에 매우 옅게 남은 채 다음 실사 숏으로 바뀐다.
- 자산관리 카피는 009→011에서 들어온다. 009에서 왼쪽 제목이 강한 블러/약 0.15 불투명도, 010에서 약 0.5, 011에서 선명한 완전 불투명 상태다. 같은 구간 동안 폰 렌더는 거의 같은 오른쪽 위치에 고정된다.
- 판매·정산 카피는 026→028에서 들어온다. 026 하단에 큰 제목이 약 0.15로 보이고, 027에서 일부 어절만 갈색·검정으로 선명해지며, 028에서 전체 제목이 완전 불투명해진다.
- 토스애즈→페이먼츠 전환은 034→038이다. 034에서 광고 카드 레일이 위로 빠지고, 035~036에서 그래프/다음 카피가 강하게 흐린 중간 상태, 037에서 페이먼츠 UI가 나타나며, 038에서 카피와 UI가 선명해진다.
- 일상 모자이크 카피는 054→055에서 흐림이 해소된다. 054에서 제목이 약 0.2 불투명도와 강한 블러, 055에서 선명한 상태다.
- 이 장면들은 이전 문구와 다음 문구가 동시에 선명하게 겹치는 전형적 양방향 crossfade라기보다, **현재 문구를 blur+opacity로 퇴장시키고 다음 문구를 blur+opacity로 입장시키는 연속 교체**로 보인다.

## 4. Sticky 고정과 배경색 전환

- 화면 왼쪽 가장자리의 세로 진행 내비게이션은 `toss-scroll-64-120` 000~063에서 같은 x 위치에 지속적으로 붙어 있다. 각 챕터가 바뀌어도 위치가 유지되는 전역 sticky/fixed 요소다.
- 챕터 내부 고정 무대가 뚜렷하다. 자산관리 폰은 009~012에서 오른쪽, 쇼핑 결제 폰은 020~025에서 왼쪽, 판매·정산 카드 레일은 027~029, 결제 단말기 카운터는 043~053에서 같은 무대/카메라 구도를 유지한 채 콘텐츠만 교체된다.
- 대부분의 1~7장 배경은 흰색이다. 첫 명확한 흰색→검정 전환은 041→042이며, 중앙 검은 캡슐이 화면 전체 검정으로 확장된다. 검정은 042~043에서 유지되고 043부터 어두운 매장 실사 배경으로 바뀐다.
- 매장 실사→흰색 전환은 053→054에서 즉시 일어난다. 이후 흰 배경은 057까지 유지된다.
- 흰색→검정 전환은 057→058에서 다시 일어나며, 중앙 비행기 창 카드만 남는다. 검정→실사 영상은 059→060, 실사→남색 글로벌 배경은 061→062에서 일어난다. 062~064는 남색에서 회청색/분홍으로 번지는 동일 그라데이션 배경이다.

## 5. 영상 자체의 움직임

- 히어로 열차 영상은 고정 카메라에 가깝다. `toss-load-20` 003~029에서 여성의 얼굴과 폰 위치는 거의 유지되고, 창밖 풍경만 오른쪽에서 왼쪽으로 미세하게 흐르며 여성의 시선·표정이 조금 바뀐다. 뚜렷한 줌이나 패닝은 관찰 못함이다.
- 스크롤에 연결된 히어로 영상 진행은 더 크다. `toss-scroll-64-120` 002→004에서 정면 중경 → 옆얼굴 근경으로 컷이 바뀌고, 004→006에서 손과 폰을 향해 카메라가 내려가며 송금 완료 화면으로 이어진다. 이는 하나의 연속 카메라 이동이라기보다 컷 편집과 근접 숏의 조합으로 보인다.
- 쇼핑 박스 영상은 017→019에서 고정된 사선 상단 카메라를 유지하면서 상자 뚜껑이 열리고 병이 위로 튀어 올라 상자 안에 비스듬히 놓인다. 카메라 이동은 관찰 못함이다.
- 결제 단말기 구간 043~053은 같은 카운터를 좌우/정면에서 보여주는 컷 교체다. 단말기 화면 UI가 켜지고, 기기 종류가 폰형 단말기→태블릿형 단말기→얼굴인식 화면으로 바뀐다. 연속적인 카메라 워크보다 제품별 컷 전환이 중심이다.
- 여행 영상은 059의 작은 창 카드가 060에서 기내 승객의 풀블리드 실사로 확장되고, 060→061에서 승객 숏이 창밖 노을 풍경 숏으로 컷된다. 061의 구름·노을에는 약한 수평 이동감이 있지만 단일 프레임 간 정확한 카메라 방향은 특정 불가다.

## 6. 재현 시 핵심 요약

- 진입: 흰 화면 → 라운드 인셋 영상 → 풀블리드, 동시에 3개 문구를 순차 opacity 처리.
- 스크롤: 전역 세로 진행 표시 + 장별 sticky 무대. 무대는 유지하고 카피/제품 UI/미디어를 blur·opacity·scale로 교체.
- 장면 전환: 흰 제품 소개가 길게 이어진 뒤 검은 결제 인터스티셜, 다시 흰 일상 모자이크, 검은 여행 브리지, 남색 글로벌 피날레 순서.
- 이미지 지연 로딩과 애니메이션 구분: 동일 캡처를 20ms/50ms 진입 및 120ms/200ms 스크롤로 반복했으며, 반복해서 같은 프레임 범위에 나타난 blur·opacity·scale 변화만 모션으로 기록했다.
