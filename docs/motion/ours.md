# 우리 사이트 현재 모션 진단

관찰일: 2026-08-22  
관찰 환경: `http://localhost:5188`, `scripts/capture-motion.mjs`, load 16프레임(90ms 간격), scroll 20단계(300ms settle), 지정 click/hover 캡처. 아래 판정은 생성된 컨택트시트를 직접 열어 비교한 결과다.

## 총평

현재 모션은 사실상 `opacity 0→1 + y 20px` reveal 한 종류뿐이다. 홈 첫 진입에서는 프레임 000→003 동안 헤드라인·본문·버튼·이미지가 순서대로 나타나 최소한의 시작감이 있지만, 나머지 다섯 경로의 load는 프레임 001 이후 거의 완전히 정지한다. 스크롤 시에도 새 섹션이 잠깐 흐린 중간 상태를 보이는 경우 외에는 카드, 수치, 타임라인, 오브젝트가 모두 고정된 인쇄물처럼 놓인다.

결과적으로 페이지의 정보 구조는 읽히지만 “AI대학 출범”의 추진력이나 시스템성을 전달하는 동세가 없다. reveal도 모든 요소가 같은 방향·거리·속도로 움직여, 몇 번 본 뒤에는 모션이라기보다 화면이 늦게 선명해지는 현상으로 느껴진다.

## 경로별 관찰과 전환이 없는 자리

### `/`

- load 프레임 000→001: 헤드라인 두 번째 줄이 추가되며 첫 줄도 선명해진다. 프레임 001에서는 본문이 매우 옅고, 002에서 본문·버튼이 선명해지며 하단 히어로 이미지가 진입한다. 프레임 002→003에서 이미지가 아래쪽에서 약 20px 올라오며 선명해진 뒤 003→015는 완전 정지다.
- 실제 인상: 여섯 경로 중 유일하게 첫 화면에 단계감이 있으나 약 270ms 안에 끝나고, 이후 히어로 대형 이미지 자체에는 패럴랙스·확대·오브젝트 반응이 없다.
- scroll 프레임 006→008에서 뉴스 카드 묶음이 화면에 들어오지만 카드별 시차, 숫자/선 강조, hover 암시는 없다. 프레임 011→014의 “부산대학교 AI대학” 정보 표도 단순히 스크롤 위치만 바뀐다.
- 전환 없음: 히어로 사진의 이동/깊이 효과, 뉴스 카드 3장의 순차 진입, 카드 hover, 정보 표 행의 순차 강조, 섹션 간 배경/색 전환, 푸터 진입.

### `/ai-college`

- load 프레임 000에서 상단 소개가 흐리고 001에서 선명해진다. 프레임 001→015는 제목, 다음 섹션 헤드라인 모두 같은 위치·불투명도로 고정되어 진입 동세를 거의 느낄 수 없다.
- scroll 프레임 001→002에서 `why_converge` 오브젝트와 설명이 들어오고, 프레임 004→008에서 ADP+X 카드들이 노출되지만 카드별 순차성이나 축 간 연결 모션은 없다. 프레임 009→011의 `axis_stat` 이미지와 424·17·256·300 수치는 완성 상태로 나타나며 카운트업은 관찰 못함.
- 프레임 013→016의 참여 조직 카드, 017→020의 진로 행도 위치 변화 외 전환이 없다.
- 전환 없음: `why_converge` 오브젝트의 회전/부유/형태 변화, 네 축 카드의 stagger, 숫자 카운트업, 참여 조직 간 연결선/흐름, 진로 행 순차 강조, CTA hover.

### `/ai-college/adpx`

- load 프레임 000의 설명이 흐리고 001에서 선명해진 뒤 001→015 전체가 정지한다. 첫 화면의 축 목록/콘텐츠는 아래에 잘려 있어도 이를 예고하는 동세가 없다.
- scroll 프레임 002→005에서 A/D/P/X 설명이 순서대로 화면에 들어오지만 각 글자는 고정 아이콘일 뿐 연결되거나 변형되지 않는다. 프레임 006→011의 학부 탭과 `axis_a` 오브젝트도 스크롤 이동 외 모션이 없다.
- 프레임 012→017의 “하나의 문제가 네 번 손을 바꿔요” 단계 목록은 원형 D/A/P/X가 완성 상태로 추가될 뿐, 단계 간 선·handoff·진행 모션이 없다.
- 전환 없음: A/D/P/X 축 소개의 연결/조립, 탭 hover/선택 이동 인디케이터, 탭 패널 cross-fade/slide, 오브젝트 morph/cross-fade, 전공 handoff 단계의 순차 진행, 하단 결론 강조.

### `/ai-college/schools`

- load 프레임 000에서 타이틀·카드가 흐리고 001에서 선명해진 뒤 001→015는 정지다.
- scroll 프레임 002→011에서 카드가 2개→4개→5개로 화면에 들어오지만 이는 스크롤 노출뿐이다. 개별 카드의 stagger, hover elevation, 축 색/아이콘 변화는 관찰 못함.
- 프레임 012→020은 마지막 카드와 푸터가 단순히 위로 지나간다.
- 전환 없음: 5개 학부 카드 stagger, 카드 hover/press, 축 배지 반응, 카드→상세 경로 전환, 빈 공간을 활용한 축 연결 시각화, 푸터 진입.

### `/ai-college/schools/ai-computer`

- load 프레임 000→001에서 상단 소개가 선명해지는 정도이고, 기본 정보와 `axis_a` 이미지는 처음부터 거의 완성 상태다. 프레임 001→015는 정지다.
- scroll 프레임 003→005의 교육 소개, 프레임 007→020의 긴 교원 목록은 대부분 정적인 텍스트/행이다. 특히 교원 목록은 화면 대부분을 차지하지만 행 stagger, hover, 펼침 예고가 전혀 없어 가장 죽어 있는 구간이다.
- 전환 없음: 기본 정보 행 순차 진입, 오브젝트 부유/반응, 키워드 칩 stagger/hover, 교원 행 hover, 펼침 chevron 회전, 상세 패널 높이/opacity 전환, 긴 목록 탐색 보조.

### `/ai-college/roadmap`

- load 프레임 000→001에서 타이틀이 선명해진 뒤 001→015가 완전히 동일하다. `roadmap_path` 이미지도 고정된 완성 이미지다.
- scroll 프레임 003→010에서 2026~2030 타임라인 항목이 화면에 들어오지만 선이 그려지거나 현재 연도가 이동하는 효과는 없다. 프레임 012→017의 수시모집 카드도 완성 상태로 등장한다.
- 전환 없음: `roadmap_path` 오브젝트의 진행/균형 변화, 세로 타임라인 선 draw, 연도별 노드 순차 활성화, 현재 2027 노드 pulse, 모집 카드 reveal/hover, CTA hover.

## 상호작용

### ADP+X 학부 탭

- `button[role=tab]:nth-of-type(2)` 클릭 전 프레임 000은 A 탭, AI컴퓨터공학부, 파란 큐브(`axis_a`)다.
- 프레임 000→001 사이 선택 배경이 즉시 D 탭으로 이동하고, 제목·설명·버튼과 오브젝트가 동시에 데이터사이언스학부·통계학과 및 종 모양 `axis_d`로 교체된다.
- 프레임 001→012는 완전히 동일하다. 중간 반투명, 이동 중, 크기 변화 중인 프레임이 하나도 없어 탭 전환은 즉시 튄다. 오브젝트 이미지가 바뀌는 것은 명확히 보이지만 cross-fade나 morph는 관찰 못함.

### AI컴퓨터공학부 경력 펼치기

- 프레임 000은 교원 목록, 프레임 001은 첫 행 상세가 펼쳐진 상태다. 000→001 사이 중간 높이 상태 없이 패널이 즉시 삽입된다.
- 삽입으로 문서 높이와 캡처 기준 위치가 크게 바뀌어 프레임 001→002에서 화면이 소속 교원 영역에서 위쪽 교육 소개 영역으로 급격히 점프한다. 프레임 002→003에서 다시 교원 영역으로 이동하고 003→012는 고정된다.
- 따라서 부드러운 아코디언이 아니라 즉시 레이아웃이 튀는 상호작용으로 보인다. 높이 애니메이션, 상세 opacity, chevron 회전은 관찰 못함.

### 헤더 NavLink hover

- `header nav a:nth-child(2)` hover 캡처에서 프레임 000→001 사이 대상 링크가 옅은 회색 배경으로 즉시 바뀐다. 프레임 001→010은 동일하다.
- 배경색 tween, 밑줄 이동, 글자색 변화의 중간 상태는 관찰 못함. 최소한의 hover 피드백은 있으나 즉시 on/off되는 정적 강조다.

### 라우트 이동

- 홈에서 `/ai-college` 링크 클릭 시 프레임 000은 홈 화면, 프레임 001은 이미 AI대학 페이지 레이아웃으로 완전히 교체된 상태다. 두 페이지가 겹치거나 나가고 들어오는 중간 프레임은 없다.
- 프레임 001→002에서 새 페이지 텍스트가 흐린 상태에서 선명해지는 것은 새 페이지의 기존 reveal일 뿐, 라우트 전환 자체가 아니다. 즉 route exit/enter, shared element, wipe, cross-fade는 없다.

## 3D 오브젝트 세트 판정

요청에는 “7장”이라고 되어 있으나 열거된 파일은 `axis_a/d/p/x` 4장 + `axis_stat` + `why_converge` + `infra_gpu` + `roadmap_path`로 총 8장이다.

시각 스타일 자체는 흰/연회색 배경, 파란 반투명 재질, 부드러운 바닥 그림자로 통일돼 있어 정지 이미지 자산으로는 한 세트처럼 보인다. 근거로 `/ai-college` scroll 프레임 001→002의 `why_converge`, 009→011의 `axis_stat`, `/ai-college/adpx` scroll 프레임 008→011의 `axis_a`, `/roadmap` load 프레임 001→015의 `roadmap_path`가 같은 조명·재질 언어를 공유한다.

그러나 페이지 경험에서는 따로 논다. 서로 다른 경로와 먼 스크롤 지점에 고립되어 있고, 공통 진입·부유·회전 규칙이나 축 간 morph가 없다. 가장 직접적인 증거는 ADP+X 탭 프레임 000→001에서 `axis_a`가 `axis_d`로 중간 상태 없이 교체되는 장면이다. 자산의 외형은 세트지만, 모션 시스템으로 묶인 세트는 아니다. `infra_gpu`는 이번 6개 경로의 캡처 프레임에서 식별 가능한 형태로 관찰 못했으므로 해당 이미지의 실제 동작은 판정하지 않는다.

## 우선 채울 모션 공백

1. 라우트 전환: 현재 프레임 000→001에서 화면이 통째로 교체된다.
2. 탭/아코디언: 현재 둘 다 중간 프레임이 없고, 아코디언은 큰 레이아웃 점프까지 만든다.
3. 오브젝트 시스템: 동일 재질 자산을 공통 idle motion과 축 간 cross-fade/morph로 연결할 필요가 있다.
4. 긴 정적 구간: 교원 목록, 학부 카드 그리드, 로드맵 타임라인, 대학 정보 표에 행/카드 단위의 절제된 stagger와 hover가 없다.
5. 데이터/진행 표현: 424·17·256·300 수치와 2026~2030 타임라인이 완성 상태로만 나타나 의미 있는 변화가 없다.
