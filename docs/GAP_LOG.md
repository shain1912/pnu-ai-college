# toss 격차 기록

`node scripts/gap.mjs [경로] [단계수]` 로 toss.im 과 배포본을 같은 스크롤 깊이에서
나란히 찍는다. 왼쪽 열이 toss, 오른쪽 열이 우리, 행이 스크롤 깊이다.

격차를 매번 사람이 찾아내야 했기 때문에 만들었다. 비교가 싸지면 변경마다 돌릴 수 있다.

## 회차 1 — 히어로가 정지 루프였다

| | |
|---|---|
| 고른 격차 | 스크롤해도 장면이 전개되지 않고 5초 루프가 제자리에서 돌았다. 문구도 고정이었다. |
| 근거 | toss 는 프레임 000→001 에서 헤드라인이 밀려나며 흐려지는 동시에 다음 장면이 자리를 넘겨받고 새 문구가 얹힌다 |
| 고친 것 | 섹션을 네 화면 높이로 두고 안쪽 무대를 sticky 로 붙였다. 스크롤이 무대를 밀어내는 대신 장면을 진행시킨다. 장면과 문구가 blur+opacity 로 함께 교체된다. |
| 부수적으로 | 영상 소재도 바꿨다. 아트리움은 AI대학과 무관한 빈 건물이었다. 네 장면이 ADP+X 가치사슬 자체를 설명하게 했다. |
| 재측정 | 좁혀짐. 행 0~2 에서 두 사이트가 같은 종류의 화면으로 읽힌다. |

## 남은 격차

- **행 4** — toss 는 어두운 풀블리드 제품 장면이 계속되는데 우리는 표가 이어진다.
  스펙 표를 없앨 수는 없다. 표 자체를 장면처럼 다루는 방법을 찾아야 한다.
- **미디어 종류가 한 가지다.** toss 는 실사 영상·제품 목업·카드 레일·다크 카드를
  계속 교차시킨다. 우리는 유리 오브젝트 하나로 전 페이지를 끌고 간다.
  실사 인물 컷은 검증에서 전량 불합격 나 폐기했다(깨진 텍스트·비한국인·금지색).
  다시 시도하려면 그 결함을 프롬프트에 명시해야 한다.
- **배경 전환이 적다.** toss 는 흰색 → 검정 → 흰색 → 남색으로 장마다 바뀐다.
  우리는 424 블루 면이 유일한 강조면이다.

## 5회차 — 히어로 영상을 클라이언트 편집본으로 교체

**클라이언트 지적**: "내가 만든 영상이 훨 나은데 코덱스가 만든 것보다. 왤케 추상적으로 만들어."

맞다. 원인은 코덱스가 아니라 내가 잡은 형태 언어다. 라이브액션 자산이 품질
검수에서 떨어진 뒤 "밝은 갤러리에 놓인 반투명 유리 오브젝트"로 고정했고,
재생성할 때마다 그 언어를 계속 강제했다. 그 결과 어느 컷도 한 마디로
무엇인지 말할 수 없었다. 연구실도 데이터도 공정도 부산대도 보이지 않았다.

`spliced.mp4` 는 컷마다 주어가 있다. 로봇 팔이 있는 연구실 / 데이터 비 /
궤도를 도는 입자 구름 / 자율주행차 / 기어를 조립하는 산업 로봇 / 부산대
엠블럼. 사이는 워프로 넘어간다.

| 슬롯 | 구간 | 무엇이 보이나 |
|---|---|---|
| 히어로 전체 | 0–10s | 스크롤에 물린 편집본 전체 |
| axis_d | 2.05–3.32 | 데이터 비 |
| axis_a | 3.45–4.36 | 입자 구름 + 궤도 링 |
| axis_x | 5.75–6.62 | 자율주행차 |
| axis_p | 6.80–7.92 | 산업 로봇 + 기어 |
| axis_stat | 2.60–3.30 | 데이터 비 (왼쪽 크롭, 0.5배속) |
| schools | 4.60–5.50 | 워프 (출범) |
| apex | 1.25–1.92 | 연구실 전경 (0.5배속) |
| infra_gpu | 0.25–1.15 | 로봇 손 + 홀로 인터페이스 |
| chain | 4.95 | 워프 정지컷 |
| roadmap_path | 6.05–6.62 | 차선이 뻗는 화면 (0.5배속) |
| emblem | 9.5 | 부산대 엠블럼 정지컷 |

남긴 추상: `asis` / `tobe` 뿐이다. "지금 흩어져 있고 앞으로 맞물린다"는
비교 자체가 은유라 흩어진 파편과 완성된 다면체가 영상 어느 컷보다 정확하다.

**측정**: 배포본 재캡처에서 행 0 헤드라인이 60% 불투명도·4px 블러로
착지하던 것을 발견해 인트로 문구 창을 0 에서 시작하도록 고쳤다. 재측정에서
또렷하게 착지한다.

**크레딧**: 25.68 남음. 힉스필드 재생성은 사실상 끝났고, 앞으로 자산이
필요하면 이 편집본에서 잘라 쓴다.

## 6회차 — 워프가 스크롤을 먹던 것

**측정**: 배포본을 toss 와 6단계로 나란히 찍었다. 행 2 와 행 3 이 **둘 다 워프**였다.
문구 없는 화면이 두 스크린 연속이다. toss 는 여섯 행 전부 문구가 있다.

**원인**: 스크롤 진행률을 영상 시간에 그대로 비례시켰다. 4.40–5.67 워프는
1.27초뿐인데 전체의 12.7%, 700svh 중 89svh 를 가져갔다. 영상 안에서는
1.27초에 지나가는 전환이 스크롤에서는 한 스크린 가까이 늘어난 셈이다.

**고침**: 컷별 스크롤 배분(`SEGMENTS`)을 도입해 워프 두 구간만 0.28배로 눌렀다.

| 컷 | 전 | 후 |
|---|---|---|
| 워프 (4.40–5.67) | 89svh | 28svh |
| 워프 (7.96–8.40) | 31svh | 10svh |

나머지 컷은 80–152svh 를 받는다. 편집은 그대로다. 바뀐 것은 스크롤 한 칸이
몇 초를 넘기느냐뿐이다.

**재측정**: 로컬 14단계에서 히어로 표본 10개가 전부 문구를 달고 있고 문구
없는 화면은 하나도 잡히지 않았다. 배포 후 6단계 재측정에서도 행 0–3 이
각각 헤드라인 / D / X / 엠블럼으로 채워졌다. 좁혀졌다.

**힉스필드 대기열**: 정리했다.
- `hf-queue.mjs` 가 `execFile` 에 인자까지 붙은 한 줄을 넘기고 있었다.
  PowerShell 에서는 우연히 통과하지만 bash 에서는 ENOENT 로 죽는다. `exec` 로 고쳤다.
- 죽은 작업 하나가 큐 전체를 멈추던 것도 고쳤다. `Job not found` 는 이제
  그 항목만 버리고 넘어간다.
- `scene_d/a/p/x` 네 건은 작업이 만료돼 복구 불가. 재제출하면 40크레딧인데
  잔액이 25.68 이고, 히어로가 클라이언트 편집본으로 바뀌어 쓰이지도 않는다. 제거.
- `t_px` 는 seedance 45크레딧이라 제출 자체가 불가능. 제거.
- **힉스필드 대기열은 이것으로 끝이다.** 앞으로 자산은 편집본에서 잘라 쓴다.

**다음 격차**: toss 행 3 은 화면 밖으로 잘려나가는 가로 카드 레일이다.
우리 행 4 는 3열 고정 그리드라 더 볼 것이 있다는 신호가 없다.

## 7회차 — 가로로 움직이는 것이 하나도 없었다

**관찰**: toss 를 0.470~0.545 여섯 단계로 찍어 비교했다.
`assets/motion/toss-rail-move.jpg`

- 0.485 — 레일 맨 왼쪽이 「혜택이 잘 보이는 리스트 광고」
- 0.500 — 맨 왼쪽이 「자동 플레이되는 동영상 광고」, 앞 두 장은 왼쪽으로 잘려나감

페이지가 1.5% 내려가는 동안 레일이 **카드 두 장만큼 왼쪽으로 갔다.** 제목은
제자리고 레일만 움직인다. CSS 를 읽어서가 아니라 두 프레임을 나란히 놓고 확인했다.

**격차**: 우리에게는 가로로 움직이는 것이 하나도 없었다. 바로 가기는 3열 고정
그리드라 카드가 양끝에서 딱 끊긴다 — 셋이 전부라는 인상이다. 홈에는 학부 섹션
자체가 없기도 했다. CORE.md 가 요구한 편제 대상 학부·학과가 서브페이지에만 있었다.

**고침**: `SchoolRailScene` — 학부 다섯 곳을 세로 스크롤이 미는 가로 레일로.

- 이동 거리를 상수로 박지 않고 매번 `scrollWidth - clientWidth` 를 잰다.
  카드 폭과 화면 폭이 뷰포트마다 달라 상수로 두면 좁은 화면에서 끝까지 못 가고
  넓은 화면에서는 빈 자리가 생긴다.
- 레일을 `edge` 컨테이너 **밖**에 뒀다. 안에 가두면 양끝에서 딱 끊겨 더 있다는
  신호가 사라진다.
- 카드 영상은 5회차에 편집본에서 잘라둔 축별 화면을 그대로 쓴다.

**잡은 것**: D축 두 단위는 원문에 학부 단독 정원이 없어 합산 114명만 있다.
`D축 114명 (통계학과 포함)` 으로 적었더니 **통계학과 카드에 그대로 찍혀 자기를
가리켰다.** `D축 합산 114명` 으로 바꿨다.

**재측정**: 배포 후 7단계.

| 행 | toss | 우리 |
|---|---|---|
| 0 | 전면 영상 + 헤드라인 | 전면 영상 + 헤드라인 |
| 2 | 전면 제품 화면 | 전면 영상 |
| 6 | 「토스가 바꾼 일상」 + 사진 카드 줄 | 「424명이 이 다섯 곳으로」 + 영상 카드 줄 |

행 6 이 같은 형태가 됐다. 좁혀졌다.

**다음 격차**: 히어로가 끝나자마자 바로 가기 3열 카드가 붙고 그 뒤에 424 블루 판이
바로 온다. 밀도 높은 블록이 쉬는 화면 없이 이어진다. toss 는 밀도 높은 구간 사이에
문장 하나만 놓인 화면을 넣는다 (§2-8 「온오프라인 경계 없이」).

## 8회차 — 바로 가기 제거, 한눈에 보기 재작업

**클라이언트 지적**: 바로 가기 3열 카드 없애고, 한눈에 보기부터 처참하다.

원본 해상도(1440px)로 다시 보니 세 가지가 겹쳐 있었다.

1. **평평한 파란 사각형 + 엠블럼 워터마크.** 히어로는 여백을 둔 둥근 카드인데
   이건 각진 전면 사각형이라 기하가 충돌한다. 파란 면 자체도 빈 판이었다.
2. **읽고 있지 않은 행을 0.4 로 죽였다.** 여덟 줄 중 일곱 줄이 회색이라 강조가
   아니라 로드 실패로 보였다. toss 는 본문을 죽이는 일이 없다. 5회차에 toss
   §2-2 무대 고정을 옮겨온 것인데, toss 는 **무대를 고정하고 카피를 교체**하지
   본문 목록을 흐리지 않는다. 패턴을 잘못 옮겼다.
3. **왼쪽 정사각 영상 + 오른쪽 긴 표.** 표가 훨씬 길어 영상 아래로 빈 공간이
   화면 절반 넘게 남았다. 제목 「부산대학교 AI대학」은 고정 내비에 걸려 잘렸다.

**다시 짠 구성** — toss 리듬 그대로.

| 자리 | 내용 | toss 근거 |
|---|---|---|
| 쉬는 화면 | 흰 바탕 424 하나 + 214/114/69/27 한 줄 | §2-8 흰 화면 문장 하나 / Toss Ads 큰 문장 밑 지표 줄 |
| 이미지 띠 | 글자 없는 연구실 화면, 히어로와 같은 둥근 카드 | 제품 사진 구간 (프레임 015~018) |
| 표 | 규모 / 구조 / 준비 상황 세 묶음, 전부 또렷하게 | — |

띠는 처음에 apex(560x560)를 3:1 로 늘려 흐렸다. 원본에서 1920x640 을 잘라
1600 폭 `band_lab` 으로 새로 뽑았다.

## 10회차 — 어두운 화면 넷이 연달아 나오고 끝나던 것

## 11회차 — 에셋 색감이 사이트와 안 맞던 것

**클라이언트 지적**: 에셋부터가 색감이 사이트랑 안 맞는다.

감으로 판단하지 않으려고 `scripts/hue.mjs` 를 만들었다. 채도·밝기가 일정 이상인
화소만 골라 색상각 히스토그램을 낸다. dominant 색은 배경(거의 검정)이라 팔레트
비교에 못 쓴다.

**재보니 지적이 맞았다.**

| | 색상각 | 브랜드와 차이 |
|---|---|---|
| 사이트 `#3182f6` | **215°** | — |
| 워프 (chain, schools) | 250° | 35° |
| 데이터 비 (axis_d, axis_stat) | 190° | 25° |
| 9회차 생성분 4장 | 190~200° | 15~25° |
| 자율주행차 (axis_x) | 200° | 15° |
| 입자 구름 (axis_a) | 220° | 5° |

9회차 생성분이 청록으로 간 이유는 **내 프롬프트가 "cyan and magenta rim light"
라고 못박았기 때문이다.** 브랜드색을 확인하지 않고 편집본 느낌만 보고 적었다.

**두 갈래로 고쳤다.**

*(1) 편집본에서 잘라 쓴 타일 — 색상 회전.* 히어로 원본은 건드리지 않는다.

  axis_d, axis_stat  +20  ·  axis_x  +12  ·  infra_gpu  +15

회전 폭은 눈으로 골랐다. axis_x 를 +15 로 돌렸더니 오른쪽 보라 패널이 분홍이 돼서
회전을 +12 로 줄이고 크롭을 x=120 으로 옮겨 그 패널을 화면 밖으로 뺐다.

워프는 -25 로 돌려도 줄기의 보라·녹색이 휘도에 박혀 안 빠졌다. -35 이상 돌리면
녹색이 더 섞인다. 채도를 눌러도 회색빛 보라가 남았다. **회전을 포기하고
브랜드색으로 새로 생성해 갈았다** (`warp_blue`).

*(2) 새로 생성 — 팔레트를 그림으로 물린다.* 프롬프트에 "azure blue" 라고 적는
것만으로는 또 청록으로 흐른다. `scripts/palette.mjs` 로 사이트 토큰 9단계 램프판을
만들어 `--image-references` 로 넣고, 청록·틸·마젠타·보라·녹색을 금지어로 박았다.

| 슬러그 | 무엇 | 왜 |
|---|---|---|
| `port_crane` `gpu_rack` `lecture` `shipyard` | 9회차분 재생성 | 190~200° → 210° |
| `campus_night` | 블루아워 공학관 | /ai-college 에 여는 화면이 없었다 |
| `studio_team` | 학생 넷 뒷모습 + 네트워크 도표 | 사람이 강의실 한 장뿐이었다 |
| `data_wall` | 차트·산점도 벽 | 통계학과가 데이터사이언스학부와 같은 화면을 써서 레일에서 두 카드가 거의 같아 보였다 |
| `roadmap_path` | 어두운 공간의 상승 경로 | 기존은 자율주행차 재탕 |
| `warp_blue` | 방사형 블루 버스트 | 250° 워프 대체 |

**두 번 다시 뽑은 것**: `studio_team` 첫 결과가 **학사모와 가운**을 입혔다.
2027년 출범이라 졸업생이 있을 수 없다. `roadmap_path` 는 흰 배경으로 나와 나머지와
언어가 달랐다. 둘 다 프롬프트에 명시적 금지를 넣어 다시 뽑았다.

**결과**: 전체 타일 색상각 폭이 **190~250° (60°) → 210~230° (20°)**, 브랜드 215° 중심.

**배선**: `MediaBand` 컴포넌트를 만들어 /ai-college 에 campus_night, studio_team 두
띠를 넣었다. 통계학과 카드는 data_wall 로 갈아 레일의 중복을 없앴다.

**크레딧**: 이미지 11장 22 + 영상 8편 80 ≈ 102. 잔액 ~640.

**겪은 것**: 백그라운드 큐 두 개가 같은 `assets/queue.json` 을 덮어써서 영상 6건이
사라졌다. 큐 파일을 나눠서 다시 돌렸다.

## 12회차 — 문장 하나만 놓인 화면이 없었다

**측정**: 배포본 8단계. toss 행 5 는 흰 화면 한가운데에 검은 형태 하나가 서 있고
그 좌우로 「온오프라인」「경계 없이」가 갈라져 있다. 다른 요소가 하나도 없다.
앞은 광고 카드 레일, 뒤는 제품 사진 — 둘 다 빽빽하고 이 화면이 그 사이에서
눈을 쉬게 한다.

우리에게는 그렇게 조용한 화면이 없었다. **모든 절이 눈썹 문구 + 제목 + 본문 +
보조 정보 네 겹을 한꺼번에 편다.**

**고침**: 표(규모·구조·준비 상황)와 학부 카드 줄 사이에 문장 하나만 놓인 화면.
toss 가 그 화면을 레일과 제품 사진 사이에 둔 것과 같은 자리다.

문장은 「AI는 한 학과가 감당할 수 있는 크기를 넘었어요」. 홈은 AI대학이 무엇인지,
몇 명인지, 어느 학부가 오는지는 말하는데 **왜 만드는지는 한 번도 말하지 않았다.**
그 답이 `/ai-college` 안쪽에만 있었다. 빈 자리 두 개를 한 번에 메운다.

toss 는 문장을 좌우로 갈라 사이에 오브젝트를 세우지만 우리는 한 덩이로 뒀다.
「온오프라인」「경계 없이」는 끊어도 각각 뜻이 서는 짧은 구인데, 우리 문장을
자르면 읽는 순서가 흔들린다.

처음에 88svh + 80px 로 잡았더니 앞 절의 아래 여백과 겹쳐 400px 넘는 빈 화면이
생겼다. 74svh + 64px 로 줄이고 표 절의 아래 여백을 걷었다.

**재측정**: 배포 후 10단계. **행 6 이 정확히 맞았다** — toss 「온오프라인 경계
없이」, 우리 「AI는 한 학과가 감당할 수 있는 크기를 넘었어요」. 같은 깊이에 같은
성격의 화면이 섰다. 좁혀졌다.
