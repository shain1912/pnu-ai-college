# toss 격차 기록

`node scripts/gap.mjs [경로] [단계수]` 로 toss.im 과 배포본을 같은 스크롤 깊이에서
나란히 찍는다. 왼쪽 열이 toss, 오른쪽 열이 우리, 행이 스크롤 깊이다.

격차를 매번 사람이 찾아내야 했기 때문에 만들었다. 비교가 싸지면 변경마다 돌릴 수 있다.

## 회차 1 — 히어로가 정지 루프였다

| | |
|---|---|
| 고른 격차 | 스크롤해도 장면이 전개되지 않고 5초 루프가 제자리에서 돌았다. 문구도 고정이었다. |
| 근거 | toss 는 프레임 000→001 에서 헤드라인이 밀려나며 흐려지는 동시에 다음 장면이 자리를 넘겨받고 새 문구가 얹힌다 |
| 고친 것 | 섹션을 네 화면 높이로 두고 안쪽 무대를 sticky 로 붙였다. 스크롤이 무대를 밀어내는 대신 장면을 진행시킨다. 장면과 문구가 blur+opacity 로 함께 교체된다. |
| 부수적으로 | 영상 소재도 바꿨다. 아트리움은 AI대학과 무관한 빈 건물이었다. 네 장면이 ADP+X 가치사슬 자체를 설명하게 했다. |
| 재측정 | 좁혀짐. 행 0~2 에서 두 사이트가 같은 종류의 화면으로 읽힌다. |

## 회차 2 — 히어로가 끝나면 문서로 무너졌다

| | |
|---|---|
| 고른 격차 | 행 3~4 에서 toss 는 끝까지 화면을 채우는 장면이 이어지는데 우리는 정의 목록 나열이 된다 |
| 근거 | `assets/gap/home.jpg` 행 3 — toss 는 다른 요소가 거의 없는 화면에 "온오프라인 경계 없이" 한 문장만 크게 놓는다. 정보 밀도가 높은 구간 사이에 숨 쉬는 화면을 끼워 리듬을 만든다. |
| 고친 것 | 팩트시트 앞에 424 를 놓은 전체 화면 선언을 두었다. 표 안의 한 행으로 묻혀 있던 가장 강한 증거를 화면 하나로 올렸다. 이어지는 표도 2열 격자로 바꿔 각 항목이 읽을 거리를 갖게 했다. |
| 바꾼 것 | toss 는 검정 배경을 쓰지만 브랜드 블루 면을 썼다. 국립대 페이지에 검정 인터스티셜은 톤이 맞지 않는다. |
| 재측정 | 좁혀짐. 행 3 에서 양쪽 모두 전체 화면 선언이 됐다. |

## 남은 격차

- **행 4** — toss 는 어두운 풀블리드 제품 장면이 계속되는데 우리는 표가 이어진다.
  스펙 표를 없앨 수는 없다. 표 자체를 장면처럼 다루는 방법을 찾아야 한다.
- **미디어 종류가 한 가지다.** toss 는 실사 영상·제품 목업·카드 레일·다크 카드를
  계속 교차시킨다. 우리는 유리 오브젝트 하나로 전 페이지를 끌고 간다.
  실사 인물 컷은 검증에서 전량 불합격 나 폐기했다(깨진 텍스트·비한국인·금지색).
  다시 시도하려면 그 결함을 프롬프트에 명시해야 한다.
- **배경 전환이 적다.** toss 는 흰색 → 검정 → 흰색 → 남색으로 장마다 바뀐다.
  우리는 424 블루 면이 유일한 강조면이다.

## 회차 3 — 대기열이 순서에 막혀 완성품을 못 가져왔다

| 재측정 | `t_da` `t_ap` 회수·변환 완료 |

## 회차 4 — 팩트 구간에 미디어가 없었다

| | |
|---|---|
| 고른 격차 | 행 4 에서 toss 는 풀블리드 제품 장면인데 우리는 미디어 없는 표만 이어진다 |
| 근거 | `assets/gap/home.jpg` 행 4 |
| 고친 것 | toss §2-2 의 무대 고정 구조를 팩트 구간에 적용했다. 왼쪽 오브젝트를 sticky 로 붙이고 오른쪽 팩트 목록이 지나간다. 읽고 있는 항목만 선명하고 나머지는 물러난다. 항목이 속한 묶음이 바뀌면 오브젝트도 교체된다. |
| 판단 | 스크롤 비율이 아니라 뷰포트 중앙에 가장 가까운 행을 기준으로 삼았다. 행 높이가 고르지 않아 비율로 잡으면 아직 이전 묶음을 읽는 중에 오브젝트가 바뀐다. |
| 재측정 | 좁혀짐. 프레임 007→008 에서 오브젝트가 교체되고 현재 항목만 선명하다. |
| 같은 회차 | 히어로 담당(codex)이 모프 배선을 마쳤다. 프레임 001·004 에 변형 중간 상태가 잡힌다. |

## 5회차 — 히어로 영상을 클라이언트 편집본으로 교체

**클라이언트 지적**: "내가 만든 영상이 훨 나은데 코덱스가 만든 것보다. 왤케 추상적으로 만들어."

맞다. 원인은 코덱스가 아니라 내가 잡은 형태 언어다. 라이브액션 자산이 품질
검수에서 떨어진 뒤 "밝은 갤러리에 놓인 반투명 유리 오브젝트"로 고정했고,
재생성할 때마다 그 언어를 계속 강제했다. 그 결과 어느 컷도 한 마디로
무엇인지 말할 수 없었다. 연구실도 데이터도 공정도 부산대도 보이지 않았다.

`spliced.mp4` 는 컷마다 주어가 있다. 로봇 팔이 있는 연구실 / 데이터 비 /
궤도를 도는 입자 구름 / 자율주행차 / 기어를 조립하는 산업 로봇 / 부산대
엠블럼. 사이는 워프로 넘어간다.

| 슬롯 | 구간 | 무엇이 보이나 |
|---|---|---|
| 히어로 전체 | 0–10s | 스크롤에 물린 편집본 전체 |
| axis_d | 2.05–3.32 | 데이터 비 |
| axis_a | 3.45–4.36 | 입자 구름 + 궤도 링 |
| axis_x | 5.75–6.62 | 자율주행차 |
| axis_p | 6.80–7.92 | 산업 로봇 + 기어 |
| axis_stat | 2.60–3.30 | 데이터 비 (왼쪽 크롭, 0.5배속) |
| schools | 4.60–5.50 | 워프 (출범) |
| apex | 1.25–1.92 | 연구실 전경 (0.5배속) |
| infra_gpu | 0.25–1.15 | 로봇 손 + 홀로 인터페이스 |
| chain | 4.95 | 워프 정지컷 |
| roadmap_path | 6.05–6.62 | 차선이 뻗는 화면 (0.5배속) |
| emblem | 9.5 | 부산대 엠블럼 정지컷 |

남긴 추상: `asis` / `tobe` 뿐이다. "지금 흩어져 있고 앞으로 맞물린다"는
비교 자체가 은유라 흩어진 파편과 완성된 다면체가 영상 어느 컷보다 정확하다.

**측정**: 배포본 재캡처에서 행 0 헤드라인이 60% 불투명도·4px 블러로
착지하던 것을 발견해 인트로 문구 창을 0 에서 시작하도록 고쳤다. 재측정에서
또렷하게 착지한다.

**크레딧**: 25.68 남음. 힉스필드 재생성은 사실상 끝났고, 앞으로 자산이
필요하면 이 편집본에서 잘라 쓴다.

## 6회차 — 워프가 스크롤을 먹던 것

**측정**: 배포본을 toss 와 6단계로 나란히 찍었다. 행 2 와 행 3 이 **둘 다 워프**였다.
문구 없는 화면이 두 스크린 연속이다. toss 는 여섯 행 전부 문구가 있다.

**원인**: 스크롤 진행률을 영상 시간에 그대로 비례시켰다. 4.40–5.67 워프는
1.27초뿐인데 전체의 12.7%, 700svh 중 89svh 를 가져갔다. 영상 안에서는
1.27초에 지나가는 전환이 스크롤에서는 한 스크린 가까이 늘어난 셈이다.

**고침**: 컷별 스크롤 배분(`SEGMENTS`)을 도입해 워프 두 구간만 0.28배로 눌렀다.

| 컷 | 전 | 후 |
|---|---|---|
| 워프 (4.40–5.67) | 89svh | 28svh |
| 워프 (7.96–8.40) | 31svh | 10svh |

나머지 컷은 80–152svh 를 받는다. 편집은 그대로다. 바뀐 것은 스크롤 한 칸이
몇 초를 넘기느냐뿐이다.

**재측정**: 로컬 14단계에서 히어로 표본 10개가 전부 문구를 달고 있고 문구
없는 화면은 하나도 잡히지 않았다. 배포 후 6단계 재측정에서도 행 0–3 이
각각 헤드라인 / D / X / 엠블럼으로 채워졌다. 좁혀졌다.

**힉스필드 대기열**: 정리했다.
- `hf-queue.mjs` 가 `execFile` 에 인자까지 붙은 한 줄을 넘기고 있었다.
  PowerShell 에서는 우연히 통과하지만 bash 에서는 ENOENT 로 죽는다. `exec` 로 고쳤다.
- 죽은 작업 하나가 큐 전체를 멈추던 것도 고쳤다. `Job not found` 는 이제
  그 항목만 버리고 넘어간다.
- `scene_d/a/p/x` 네 건은 작업이 만료돼 복구 불가. 재제출하면 40크레딧인데
  잔액이 25.68 이고, 히어로가 클라이언트 편집본으로 바뀌어 쓰이지도 않는다. 제거.
- `t_px` 는 seedance 45크레딧이라 제출 자체가 불가능. 제거.
- **힉스필드 대기열은 이것으로 끝이다.** 앞으로 자산은 편집본에서 잘라 쓴다.

**다음 격차**: toss 행 3 은 화면 밖으로 잘려나가는 가로 카드 레일이다.
우리 행 4 는 3열 고정 그리드라 더 볼 것이 있다는 신호가 없다.
