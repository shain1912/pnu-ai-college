# AI대학 교원 데이터 분석 및 신뢰 지표 설계

## 0. 결론 요약

- `faculty.txt`는 물리적으로 182줄이지만, 번호가 붙은 교원 레코드는 **60건**이다. 원본 설명의 ‘174행’은 스프레드시트 행 수이지 교원 수가 아니다.
- 60건은 단과대학·학과·직급·이름·세부전공·경력 전체를 기준으로 모두 서로 다르다. 이름 고유값은 59개이나, `김민우` 2건은 학과·직급·세부전공·경력이 전혀 다른 **동명이인**이므로 합치지 않는다. 따라서 중복 제거 후 실제 교원 수는 **60명**이다.
- 기업 또는 공공·출연 연구기관의 명시적 근무 이력이 확인되는 교원은 **26명(43.3%)**이다.
- 연구영역은 세부전공 필드에만 규칙 기반 다중분류를 적용했다. 한 교원이 여러 영역에 포함될 수 있으므로 영역별 합계는 60을 넘는다.
- 공개 랜딩페이지에는 개인 이름·개별 경력을 싣지 않고, **집계 수치와 산정 기준 및 기준일**만 노출하는 것이 안전하다.

## 1. 파싱 및 중복 제거 방법

재현 스크립트: `scripts/analyze_faculty.py`

```powershell
$env:PYTHONIOENCODING='utf-8'; python scripts\analyze_faculty.py
```

파싱 규칙은 다음과 같다.

1. UTF-8 BOM을 허용해 파일을 읽는다.
2. 첫 열이 정수인 줄을 새 교원 레코드로 본다.
3. 첫 열이 비어 있는 후속 줄은 직전 교원의 `주요경력(AI관련)` 필드에 이어 붙인다.
4. 완전 중복은 `단과대학+학과+직급+성명+세부전공+주요경력`이 모두 같은 경우로 정의한다.
5. 이름만 같은 경우는 자동 병합하지 않는다. 47번과 59번은 모두 `김민우`이지만 각각 데이터사이언스학부 부교수(전기컴퓨터공학)와 통계학과 조교수(베이지안·공간통계)이므로 별도 인물이다.

검증 결과는 번호 1~60이 빠짐없이 이어지고, 원시 레코드 60건과 완전 중복 제거 후 60건이 일치한다.

## 4. 산업체·연구기관 경력 집계

### 정의

‘산업체 경력을 가진 교원’은 주요경력 필드에 다음 두 조건이 함께 확인되는 경우로 정의했다.

1. 기업 또는 대학이 아닌 공공·출연 연구기관명이 명시됨: 삼성 계열, LG 계열, 금성 계열, NHN, 네이버, 하이닉스, ETRI/한국전자통신연구원, 국방과학연구소, 국가보안기술연구소, 원자력 관련 연구·안전기관, NCI 등.
2. 연구원·책임·선임·CIO·디렉터·Staff Engineer·근무·업무·재직기간처럼 실제 근무를 뒷받침하는 표현이 있음.

대학 교수·대학 연구센터 경력, 박사후연구원, 위원 활동, 과제 수행, 산학협력 실적, 학회 직함만 있는 경우는 제외했다. 인턴 경력도 근무 이력으로 인정하되, 해당 교원은 인턴 외에도 기업 직함이 있어 포함 여부가 총계에 영향을 주지 않는다.

### 결과

- 해당 교원: **26명 / 60명 = 43.3%**
- 재현용 원본 번호: **1, 2, 5, 7, 8, 9, 11, 12, 14, 15, 17, 20, 21, 24, 26, 27, 35, 38, 39, 40, 42, 43, 44, 46, 47, 57**
- 비해당 또는 증거 부족: 34명. ‘경력이 없다’는 뜻이 아니라, 제공된 필드만으로 위 정의를 충족하지 못했다는 뜻이다.

따라서 사이트 카피는 **“교원 26명이 기업·공공 연구기관 근무 이력을 보유”**가 가장 정확하다. ‘현장을 아는 교수진’은 보조 문구로 쓸 수 있지만, 전체 교수진이 산업체 출신이라는 인상을 주는 표현은 피한다.

## 5. 사이트용 신뢰 지표 5개

1. **“60명의 교원이 AI대학의 교육과 연구를 함께 설계합니다.”** — 번호가 있는 60개 레코드에서 완전 중복 0건을 확인하고, 동명이인 2건을 별도 인물로 유지해 산출했다.
2. **“교원 26명, 43.3%가 기업·공공 연구기관 근무 이력을 갖고 있습니다.”** — 60명 중 조직명과 실제 근무 표현을 동시에 충족한 26명을 집계했다. 기준일을 데이터 추출일과 함께 표기해야 한다.
3. **“교수·부교수 46명, 전체 교수진의 76.7%입니다.”** — 교수 30명과 부교수 16명을 합산하고 60명으로 나눴다. 직급 구성 이상의 의미를 부여하지 않는다.
4. **“시스템부터 산업 최적화까지, 10개 연구영역을 잇습니다.”** — 세부전공 필드에 명시한 10개 다중분류 규칙을 적용했으며, 영역별 인원 합산이 아닌 분류 범주의 개수다.
5. **“산업공학·최적화 15명, AI·기계학습 14명이 현장형 AX를 뒷받침합니다.”** — 세부전공 키워드 기준 각각 15명과 14명이다. 두 집단은 중복될 수 있으므로 29명의 서로 다른 교원이라고 표현하면 안 된다.

표현상 ‘국내 최대’, ‘최고’, ‘유일’ 같은 비교 우위는 이 교원 데이터만으로 입증되지 않으므로 붙이지 않는다.

## 6. 개인정보 및 공개 범위

### 공개 사이트에 실어도 되는 범위

- 전체 인원, 단과대학·학과·직급별 인원과 비율
- 비식별 연구영역별 인원과 분류 기준
- 비식별 산업체·공공 연구기관 경력 보유 인원과 판정 기준
- 집계 기준일, 원천 문서명, ‘중복 영역 허용’ 같은 산정 주석

### 별도 동의 또는 공식 공개 근거 없이는 싣지 않을 범위

- 성명과 개인별 세부전공·경력을 연결한 프로필
- 개인별 전·현 직장, 재직기간, 직책, 논문·특허·수상 실적
- 동명이인을 구분할 수 있는 조합 정보
- 특정 기업 출신 교원의 명단이나 개인별 ‘산업체 경력 있음/없음’ 표시
- 제공 자료에 없는 연락처, 사진, 학력, 나이 등 추가 신상 추론

`SOURCE_FACTS.md`도 이 자료를 개인 신상으로 규정하고 집계 통계만 사용하라고 명시한다. 교원 소개 페이지가 필요하다면 대학의 기존 공식 프로필을 링크하거나, 당사자 동의와 최신성 검수를 거친 별도 데이터 소스를 사용해야 한다.

## 8. 유지보수 주의사항

- 교원 이동과 승진이 발생하므로 수치 옆에 데이터 기준일을 표기하고 공개 전 원본 담당 부서 확인을 받는다.
- 원본의 소속 체계가 출범 전후로 혼재하므로, 조직 개편 완료 후 동일 인물을 새 소속으로 다시 적은 행이 추가되면 이름이 아니라 공식 교원 식별자로 중복을 제거해야 한다.
- 연구영역 키워드 규칙이 바뀌면 과거 수치와 비교할 수 없으므로 스크립트와 이 문서를 함께 갱신한다.
