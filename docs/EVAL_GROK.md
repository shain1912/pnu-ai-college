   지금 H1의 장점(학과 vs 대학)을 살리면서 날짜를 앞으로 끌어온다.

피해야 할 것: 「국내 최대」를 히어로 주어로 올리는 것. 사이트도 이미 “대학이 밝혔다”로 낮춰 썼다 (`content.js:26,37`).

## 2. 실사용 — 클릭해서 돌아다닌 결과

### 2.1 죽은 링크 · 잘못된 목적지

내부 라우트(`/`, `/ai-college`, `/adpx`, `/schools`, 5개 slug, `/roadmap`)는 모두 200으로 렌더됐다. 헤더·푸터·breadcrumb·학부 카드·「소개 →」는 같은 앱 안으로 간다.

**죽은 내부 링크는 없다. 잘못된 외부 목적지는 있다.**

- 홈 03 Google → `https://arise-ai.pusan.ac.kr/` (`Home.jsx:30`). 정답은 `/google/`.
- 홈 02 AURA → `/bymonolog`는 살아 있으나 지표가 0.
- 푸터 `https://go.pusan.ac.kr`, `https://www.pusan.ac.kr/` 는 새 탭. 이번 세션에서 입학정보 본문까지는 열어 보지 않았고, 링크 존재만 확인했다.
- 알 수 없는 경로 `http://localhost:5188/this-path-does-not-exist` → 홈으로 `Navigate replace` (`App.jsx:20-21`). 404 페이지가 없다. 오타 난 URL을 본부에 주면 “사이트 없음”이 아니라 홈이 뜬다.

### 2.3 뒤로가기 · 스크롤 복원

- 통계학과 → 브라우저 Back → ` /ai-college/schools/data-science`로 **URL은 복원**.
- 직전 스크롤은 `y=2034`였는데 복귀 후 `y=0`.
- 원인: `SiteLayout.jsx:12-18` `ScrollToTop`이 hash가 없으면 pathname 변경마다 `window.scrollTo({ top: 0, behavior: 'instant' })`. Back도 pathname 변경이다. 교원 목록 중간에서 옆 학과로 갔다가 뒤로 가면 목록 꼭대기로 튕긴다.

뒤로가기가 “깨져” 흰 화면이 되는 일은 없었다. **스크롤 복원은 깨져 있다.**

### 2.4 모바일 375px

`set viewport 375 812` 후 측정.

| 화면 | `innerWidth` | `scrollWidth > clientWidth` | 헤더 높이 |
|---|---:|---|---:|
| `/` | 375 | 아니오 (360 vs 360) | 109px |
| `/ai-college/schools/ai-computer` | 375 | 아니오 | 109px |

- 3카드는 1열로 쌓임 (`Home.jsx:126` `md:grid-cols-3`). 375에서 가로 깨짐 없음.
- 히어로 H1은 두 줄로 줄바꿈되어 읽힘.
- 헤더 하단 가로 스크롤 레일 (`SiteLayout.jsx:56-71`) — 항목 4개, 375에서 잘리거나 겹치지는 않았다.
- `html { scroll-padding-top: 88px }` (`index.css:72`)인데 실제 스티키 헤더+레일은 **109px**. 페이지 내 `#summary` 앵커가 헤더에 가려질 수 있다. 다만 홈 CTA는 `#summary`가 아니라 `/ai-college`라 (`Home.jsx:81-87`) 지금은 잘 안 탄다. `HERO.primary.href = '#summary'`는 **미사용** (`content.js:27`).

ADP+X 탭은 `grid-cols-2`라 375에서 2×2. 가로 넘침은 이 폭에서 관측되지 않았다.

### 2.5 교원 경력 펼치기 — 마우스 · 키보드

`FacultyList.jsx:81-90`. 네이티브 `<button>`, `aria-expanded`, `aria-controls`.

- `/ai-college/schools/ai-computer`에서 첫 버튼(김정구 「경력 3건」)을 눌러 「경력 접기」+ 경력 3행이 열림. 밀양대 재직 기간 등이 보인다.
- 두 번째 버튼 DOM `click()`으로 토글됨.
- 에이전트 합성 Enter는 포커스된 버튼에 닿지 않았다(임베디드 키 입력이 페이지로 안 들어감). 핸들러는 클릭 전용이고, **네이티브 button이라 실제 브라우저에서는 Space/Enter가 기본 동작으로 눌러야 한다.** 별도 `onKeyDown`은 없다. 스크린리더용 이름(「경력 3건」)과 expanded 상태는 맞다.
- 한 명만 열리게 강제하지 않음. 여러 명을 동시에 열 수 있다.
